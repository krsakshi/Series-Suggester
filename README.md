# 🎬 Series & Video Suggestor

A simple and elegant web app that suggests series and videos with a beautiful UI and built-in search functionality.

## ✨ Features

- 🎨 Clean, responsive, and modern UI
- 🔍 Real-time search filter
- 📱 Mobile-friendly design
- ⚡️ Fast and lightweight (pure HTML, CSS, and JS)
- 🌈 Gradient background and glassmorphism effects
